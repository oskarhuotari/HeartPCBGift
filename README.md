# A gift for my GF

The PCB:
A heart shaped board that has 30 leds around the outer perimeter. The MCU used is the ATMEGA32U4 and the leds are controlled using charlieplexing. The PCB has an USB-C receptacle which in addition to powering the board enables programming. 

The stand:
I also designed a stand which allows the PCB to be mounted with M3 bolts.

The code:
It registers button presses and changes between led modes. The modes are all leds on, a sweep, random led on and all leds off.
